# 月声 · ST-MoonVoice

给 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 用的朗读插件，为 **[Breeze TTS 2](https://github.com/breezeblue-ai/breeze-tts)** 适配。

角色的台词与旁白会被自动切分、逐句合成、连贯播放。**情感不是从固定词表里挑，而是由大模型直接用自然语言描述该怎么念**，再原样作为合成指令传给 Breeze——情绪表现力的上限因此从「几十个词」变成「任意描述」。

> **本插件只有「嘴」，没有「嗓子」。** 真正做推理的服务在配套的**月声整合包**里
> （解压即用、免装 Python，约 7.9 GB）。整合包 + 本插件装好，几分钟就能出声，
> 步骤见[快速开始](#快速开始)。

> ### 关于出处（请务必阅读）
>
> 本插件**派生自 [Thirteen-Moons/ST-indexTTS2-X-Player](https://github.com/Thirteen-Moons/ST-indexTTS2-X-Player) v1.2.7**（commit `aadc9ca`）。
> 而上游又可追溯到 **kirara** 的 [st-indextts-player](https://github.com/bronie-honkai/st-indextts-player)（最初以 MIT 发布），
> 历经 **xiaoxiongweihu** 与 **Thirteen-Moons** 的实质性改造。
>
> 本仓库是**第四棒**：把它从 IndexTTS2 后端适配到 Breeze TTS 2。
> 完整的署名义务见 [许可与署名](#许可与署名)。

## 特性

- **引号检测与逐句播放**：自动把正文切成一句一句，只对白/旁白合成，动作描写等装饰性内容会被跳过
- **行内播放**：台词在聊天记录里就能点读，不必等整段推理完
- **情感用自然语言描述**：`[情感描述]` 里的文字原样透传给 Breeze 作为 `instruction`
- **流式播放**：边生成边合成，长出文不必干等
- **音色库 + 逐字稿**：克隆音色必须附逐字稿，侧车负责管理，带缓存避免重复合成
- **NPC 自动分配音色**：按 `性别-年龄段` 标签打分选音色，同名角色结果确定；无标签时不会把结果写死进缓存
- **场景音效**：分「环境音效」（循环、切换场景时交叉淡入淡出）与「事件音效」（只响一次、叠在环境音之上）
- **音频间隔可调**：逐句停顿与换人额外停顿分开设置，解决「两句抢话」和「换人糊成一片」
- **悬浮播放器**：人声音量与环境音音量**分别**控制
- **局域网模式**：手机上的 SillyTavern 也能用电脑上的 Breeze 后端
- **配套整合包解压即用**：整合包内含示例音色与示例场景音效，装完即可试听

## 它是怎么搭起来的

三层，彼此只通过 HTTP 通信：

| 层 | 是什么 | 在哪 |
| --- | --- | --- |
| **扩展** | SillyTavern 扩展本体（本仓库根目录） | **本仓库** |
| **侧车** | FastAPI 小服务，管音色库/逐字稿、托管场景音效、把 `/tts` 转发给后端 | **本仓库** [`server/`](server/)，整合包里是 `sidecar/` |
| **后端** | Breeze TTS 2 推理服务（模型加载后约 7 GB 显存） | **月声整合包** `backend/`，或自取 [breezeblue-ai/breeze-tts](https://github.com/breezeblue-ai/breeze-tts) |

**后端不在本仓库内，也不打算放**：体积在 GB 量级、模型另有许可，请从整合包或上游获取。
侧车刻意做得极轻（只需要 `fastapi / uvicorn / numpy / soundfile / python-multipart`，**不需要 torch、不需要 CUDA**），因为它不做推理。

## 快速开始

四步，全程不用命令行、不用装 Python。

### 1. 拿到整合包

**月声整合包下载：** `<待填：整合包下载地址>`

整合包是**独立可用的语音生成工具**，本身不依赖本插件：解压后双击就能用浏览器合成语音。
本插件只是把它的能力接进 SillyTavern。

解压后是这个样子：

| 目录 / 文件 | 内容 |
| --- | --- |
| `backend/` | Breeze TTS 2 推理运行时（GGUF），免装 Python |
| `sidecar/` | 侧车 `moonvoice-sidecar.exe`，音色库与场景音效的接口层 |
| `data/` | 音色库与场景音效（含 22 个示例音色、9 段示例音效） |
| `文档/` | 使用说明、NOTICE、上游许可 |
| `启动后端.cmd` | 启动推理服务（端口 `7870`） |
| `启动webui.cmd` | 启动侧车 + 打开工作台（端口 `7881`） |
| `启动局域网服务.cmd` | 侧车开在 `0.0.0.0`，供手机 / 平板访问 |
| `停止全部.cmd` | 关掉上面启动的服务 |
| `放行防火墙.cmd` | 单独放行入站 `7881`（需要管理员） |

> ⚠️ **解压路径必须是纯英文、无空格。**
> 底层运行时用系统的 ANSI 代码页打开文件，路径里只要有一个中文字符
> （例如解压到 `D:\月声整合包\`），后端会直接启动失败并报
> `failed to open GGUF file ... (No such file or directory)`。
> 请解压到 `D:\MoonVoice\` 这类目录。

然后双击：

1. `启动后端.cmd` —— **第一次要十几秒到几十秒**（要加载约 7 GB 的模型），
   窗口里出现监听提示才算好了。这个窗口**不要关**。
2. `启动webui.cmd` —— 启动侧车并自动打开工作台 <http://127.0.0.1:7881/>。这个窗口也**不要关**。

想省事先确认链路通不通，可以在工作台「合成」页选一个示例音色、随便写句台词，点合成试听。
能出声就说明后端和侧车都没问题，接着装插件。

用完了双击 `停止全部.cmd`，或直接把两个黑窗口关掉。

### 2. 装扩展

本插件就是本仓库。装法二选一：

**在 SillyTavern 里装**（推荐）：扩展 → 安装扩展 → 填 `https://github.com/yukarysat/st-moonvoice-tts` → 重启。

**手动装**：

```bash
cd <SillyTavern>/public/scripts/extensions/third-party
git clone https://github.com/yukarysat/st-moonvoice-tts.git ST-MoonVoice
```

目录名必须是 `ST-MoonVoice`——SillyTavern 按文件夹发现扩展，插件内部也用它定位自己。
重启 SillyTavern 后，扩展列表里应能看到「古木兆月:月声-TTS」。

### 3. 准备音色

切到工作台的 **「音色库」** 页。整合包已经带了 22 个示例音色，可以直接用；
要建自己的，上传一段参考音频（**5~15 秒、干净单人、无背景音乐**最好），
**同时把这段音频里说的话一字不差地填进逐字稿**。

> **逐字稿是必需的，不是可选。** Breeze 的零样本克隆靠它对齐音素。
> 写错、漏字、只写「随便说点什么」都会让相似度明显下降——这是新手最常踩的坑。

在 **「合成」** 页选中音色、输入台词、点合成，可以单独试听和调参；
也可以直接在工作台里把满意的结果「保存到音色库」。
**「声音设计」** 页则是不给参考音频、直接用文字描述造一个音色。

### 4. 在 SillyTavern 里配置

扩展设置里把三个地址指向侧车：

| 设置项 | 值 |
| --- | --- |
| TTS 服务地址 | `http://127.0.0.1:7881/tts` |
| 音色克隆地址 | `http://127.0.0.1:7881/api/v1/breezetts2_cloning` |
| 音频列表地址 | `http://127.0.0.1:7881/voices` |

> 音色克隆地址这一栏会保留 `/api/v1/breezetts2_cloning` 后缀，它只被当作前缀使用
> （代码会剥掉这段再接 `/api/v1/upload`）。填完整形式最不容易出错。

地址里的 `127.0.0.1` 换成电脑的局域网 IP，手机上的 SillyTavern 就能连过来，
详见[在局域网 / 手机上使用](#在局域网--手机上使用)。

到这里应当已经能出声了：在聊天里发一句话，点朗读条试试。
如果没反应，先看[常见问题](#常见问题)。

### 5. 让模型按格式输出（可选但强烈建议）

插件靠一套固定的文本格式来识别「谁在说、怎么说、在哪儿说」：

```
[角色名|性别-年龄段][情感描述][场景]“内容”
```

这套格式需要**主模型**配合输出。设置里的「提示词注入」开关（默认**关闭**）
可以把一份写全了规范和示例的提示词注入到指定深度，打开它最省事。

> 不开注入也能用，但你要自己保证模型知道这套格式——否则台词会被识别不出来，
> 表现就是「一段回复只有零散几句被读到」。

## 输出格式

插件依赖大模型按固定格式输出，每句单开一行：

```
[角色名|性别-年龄段][情感描述][场景]“内容”
```

示例：

```
[小明|男-少年][语气轻快上扬，带着藏不住的笑意，语速偏快][]“今天的天气真好呢。”
[旁白|中性-未定][平静客观的叙述语气，语速适中，吐字清晰，情绪平稳][雨声]“他走进屋子，甩了甩伞上的水。”
[小雪|女-少年][声音低沉缓慢，带着压抑的鼻音，像刚哭过][]“我没事，真的没事。”
```

- **角色名**：后面必须跟 `|性别-年龄段` 标签，取值限定为 `男/女 × 儿童/少年/青年/中年/老年` 加 `中性-未定`，共 11 个。旁白固定 `[旁白|中性-未定]`
- **情感描述**：10~30 字，只描述「怎么说」（语气、情绪、语速、音色），**不要复述内容**。这一整段会原样作为合成指令
- **场景**：一两个词。命中 [可用环境音](#场景音效的目录约定) 里的名字就播对应音效，否则写空方括号 `[]`
- **内容**：用 `「」` 或 `“”` 包裹

插件设置里有一份可直接注入的提示词（默认**关闭**，需要你手动开启），里面写全了这套规范和示例。
它的场景清单**与整合包自带的 9 段音效逐一对齐**，所以开了注入就能直接用上场景音效；
自己加音效后记得把清单改成你的文件名（见[场景音效的目录约定](#场景音效的目录约定)）。

## 主要功能

### 逐句播放与音频间隔

正文按标点切句，只合成对白与旁白。两句之间默认留 0.25 秒；**换角色时额外再加 0.35 秒**——
同一角色连着说话只需很短换气，但换人时也这么短就会糊在一起。两者都可以在设置里调。

### 流式播放

开启后不必等整段推理结束：累计到一定句数就开始合成播放。适合长回复。

### 行内播放

对白在聊天记录里直接生成可点的朗读条，点哪句读哪句，不用等全文。

### NPC 自动分配音色

大模型临时创造的路人没有绑定音色？开启后按 `性别-年龄段` 标签自动挑选：

- 音色池**只包含带标签的音色**（根目录的留给主角手动指定）
- 打分规则：性别匹配 +2 / 部分匹配 +1 / 不匹配 −1；年龄段完全一致 +2 / 相邻 +1 / 相差 ≥2 级 −1
- 同分时用角色名的哈希值做确定性选择，同一角色每次得到同一个音色
- 角色**没有标签**时只临时选一个，**不写入缓存**——避免把配置定死

### 场景音效

两种，按文件所在文件夹自动区分：

| 类型 | 目录 | 行为 |
| --- | --- | --- |
| 环境音效 | `<数据目录>/pjy/环境音效/`，以及 `pjy/` 根目录 | **循环**播放；场景名不变就继续放；换场景时交叉淡入淡出替换 |
| 事件音效 | `<数据目录>/pjy/事件音效/` | **只响一次**，叠在环境音之上，不打断环境音 |

场景名写 `[]` 或省略第三个方括号时，当前环境音会停止。

### 悬浮播放器

独立于聊天记录的播放控制条，人声音量与环境音音量分开控制。

## 场景音效的目录约定

场景音效放在**数据目录**的 `pjy/` 下：

| 你怎么启动的 | 数据目录 |
| --- | --- |
| 整合包（`启动webui.cmd`） | `<整合包>\data\` |
| 自己跑侧车源码 | 侧车所在目录（`server/`），或用 `--data-dir` 另指 |

侧车启动时会自动创建 `环境音效/` 与 `事件音效/` 两个子目录：

```
<数据目录>/pjy/
├─ 环境音效/          <- 循环播放的 BGM / 环境声
│   ├─ 雨声.ogg
│   └─ 厨房_切菜.mp3
├─ 事件音效/          <- 只响一次的效果音
│   ├─ 开门.mp3
│   └─ 干杯.mp3
└─ （根目录下的文件也算环境音效）
```

支持 `.mp3` `.wav` `.ogg` `.m4a` `.aac` `.flac`。大模型在方括号里写的就是**去掉扩展名的文件名**。
同名时 `环境音效/` 优先于根目录。

> **整合包自带 9 段场景音效**，可以直接用。它们在磁盘上分两个文件夹，但提示词里
> 写在**同一份清单**里（插件按名字查文件，循环还是一次性由文件所在的文件夹决定）：
>
> ```
> 环境音效/（循环）：乡村_傍晚  森林  森林_清晨  森林_起风
>                  沙滩_海浪  瀑布  雨声  雨声_室内
> 事件音效/（一次）：房间_开门
> ```
>
> 想换成自己的，把音频丢进上面两个文件夹，再把提示词「可用环境音」一节里的
> **正常场景列表**改成对应的**文件名（去扩展名）**。
> 插件不校验名字，写错只会静默无声、不会报错。
>
> 本仓库**不附带任何音效文件**：体积大，且其中可能存在不适合随仓库分发的内容。
> 请自备音频，或从有明确授权的音效库获取。整合包里的那 9 段来自 SONNISS 的免费
> GameAudioGDC 音效包，授权允许随作品分发。

## 在局域网 / 手机上使用

手机上的 SillyTavern 想用电脑的 Breeze 后端，只需要把**侧车**暴露到局域网，
后端和 SillyTavern 本身都不用动。

- **整合包用户**：双击 `启动局域网服务.cmd`。窗口里会打印电脑的局域网 IP 和工作台地址
- **自己跑源码**：`python breeze_api.py --host 0.0.0.0`

然后手机上把这几个地址里的 IP 换成电脑的：

```
http://192.168.x.x:7881/tts
http://192.168.x.x:7881/api/v1/breezetts2_cloning
http://192.168.x.x:7881/voices
```

Windows 上还要放行入站 `7881`。整合包带 `放行防火墙.cmd` 做这件事（会弹 UAC，允许即可）。
手动加规则时**务必把来源限制在同一网段**：

```
netsh advfirewall firewall add rule name="MoonVoice-7881-LAN" ^
    dir=in action=allow protocol=TCP localport=7881 ^
    remoteip=LocalSubnet profile=any
```

> ⚠️ **侧车没有任何鉴权。** `--host 0.0.0.0` 意味着同一局域网内的任何人都能用你的 GPU 合成语音、
> 读取音色库与逐字稿。只在可信网络里这样用。不要把它暴露到公网。
>
> 顺带一提：**不要把 SillyTavern 本身暴露出去**——除非先开启 `basicAuthMode`。

## 常见问题

**工作台打不开 / 黑窗口一闪就没了**
按顺序排查：

1. **解压路径里有中文或空格**——这是最常见的原因，见[快速开始](#1-拿到整合包)
2. **端口被占**：后端用 `7870`，侧车用 `7881`。先双击 `停止全部.cmd` 再重试
3. 看后端窗口最后几行报错。出现 `failed to open GGUF file` 就是第 1 条

**第一次启动很久没反应**
在加载模型。第一次要十几秒到几十秒，之后启动会快一些。别急着关窗口。

**播放没反应，或浏览器控制台报连接失败**
侧车或后端没起来。先 `curl http://127.0.0.1:7881/health`，再确认 `7870` 有响应；
都没问题就回去看[快速开始](#快速开始)。

**工作台里能出声，SillyTavern 里没反应**
上面的三个地址没配对，或者侧车是后来才启动的（插件不会自动重连）——刷新 SillyTavern 页面。

**手机上什么都用不了，但手机浏览器能打开工作台**
你用的多半是**安卓第三方 App**（Tauri 系打包的酒馆）。这类 App 禁止明文 HTTP，
插件发给侧车的请求在 App 内就被拦掉了，侧车连日志都不会有——不是配置问题。
**换用手机浏览器打开酒馆即可**，不推荐使用第三方 App。

**合成很慢**
Breeze 后端加载模型本身要十几秒（第一次请求会慢），之后单句合成大致与音频时长同量级。
显存不足会让它退化得很厉害，确认后端日志里没有 OOM。

**克隆出来的声音不像**
先检查逐字稿。参考音频里说了什么，逐字稿就必须**逐字一致**地写什么，包括语气词。
另外参考音频里如果有大喊大叫的段落，会明显拉低整体效果。

**某句台词没被读到**
它可能没被识别成对白。检查是否符合[输出格式](#输出格式)——尤其别漏掉行首的两个方括号。
开了「自定义正则过滤」的话也检查一下规则有没有误伤。

**环境音不停 / 停不下来**
场景名写 `[]`（空方括号）就会停。注意场景名必须**完全相同**才会复用，
从 `雨声` 改成 `雨声_室内` 会重新开始播放。

**场景音效完全没声音**
模型写的场景名和你的文件名对不上。看后端 / 侧车所在目录的 `pjy/` 里到底有哪些文件，
再把提示词里的清单改成一样的名字（去扩展名）。名字错了不会报错，只会安静。

**NPC 的音色看起来不太搭**
音色库里的标签是否准确？打分完全依赖 `性别-年龄段` 标签。
另外在配音面板里手动指定过的角色不会被自动分配覆盖。

## 已知限制

- **不推荐用安卓第三方 App（Tauri 系打包的酒馆）**：这类 App 会禁止明文 HTTP，插件发给侧车的 `http://` 请求在 App 内就被拦掉，侧车连日志都不会有。**手机端请用浏览器打开酒馆**
- **后端必须另外获取**：本插件不含推理服务，请用月声整合包，或自己部署 Breeze TTS 2
- **解压路径只能纯英文无空格**（整合包侧的限制，见[快速开始](#1-拿到整合包)）
- **逐字稿是必需的**，Breeze 的克隆对这一点比 IndexTTS2 敏感得多
- **不支持情感向量 / LoRA**（Breeze 后端没有这些概念），情绪强度靠 `guidance_scale` 与情感描述文字调节
- 示例音色与示例场景音效只是**让你先跑通链路**用的，正式使用建议自建音色、自备音效
- 提示词里的场景清单是写死的文本，加了新音效要自己同步改；插件不会自动读 `pjy/` 生成清单

## 自己搭建后端与侧车

不想用整合包（已经有自己的 Breeze 部署、或者要跑在 Linux 上）时，插件对一个监听 `7870`
的 Breeze 兼容 HTTP 服务即可，侧车也可以直接跑源码。

### 后端

从 [breezeblue-ai/breeze-tts](https://github.com/breezeblue-ai/breeze-tts) 获取，
`audiocpp/`（GGUF，推荐）或 PyTorch 版均可，监听 `127.0.0.1:7870`。
模型权重另有独立许可。

### 侧车

```bash
cd ST-MoonVoice/server
python -m pip install -r requirements.txt
python breeze_api.py
```

要求 Python 3.9+。默认监听 `127.0.0.1:7881` 并把请求转发给 `127.0.0.1:7870`：

```bash
python breeze_api.py --backend http://127.0.0.1:7870   # 后端在别处
python breeze_api.py --host 0.0.0.0                    # 供局域网访问
python breeze_api.py --data-dir /path/to/my-data       # 音色库与场景音效放到别处
```

> 整合包里的 `sidecar/moonvoice-sidecar.exe` 就是这个服务的打包版（PyInstaller onefile），
> 支持同样的 `--host` / `--backend` / `--data-dir` 参数，只是不需要装 Python。
