# 月声 (MoonVoice) 使用说明

给 Breeze TTS 2 做的 SillyTavern 朗读插件 + 本地服务整合包。

---

## 一、开始之前：确认你的机器能跑

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 64 位 |
| 显卡 | **NVIDIA 独显**，显存 **8 GB 以上**（模型约占 7 GB） |
| 驱动 | 支持 CUDA 13.3 的较新驱动 |
| 硬盘 | 整合包解压后约 **8.1 GB**，再加音频数据，建议留 **12 GB** |
| 网络 | 只在下载时需要；解压后完全离线可用 |

> ⚠️ **解压路径必须是纯 ASCII（建议纯英文），且不要有空格。**
> 例如 `D:\MoonVoice\` ✅　`D:\月声整合包\` ❌　`C:\Program Files\月声\` ❌
>
> 这不是猜测：后端 audio.cpp 是 C++ 实现，在 Windows 上按 **ANSI 代码页**打开文件，
> 路径里出现中文等非 ASCII 字符就会打不开，报 `could not open WAV input` 之类的错误。
> 本项目已经在**参考音频**上实测并绕过了这个问题（同一文件改成 ASCII 名就能正常合成，
> 所以侧车会自动把带中文名的音色复制一份到 ASCII 临时路径），
> 但**模型文件自身的路径没有这种绕法**——所以整合包必须放在纯 ASCII 路径下。
> 启动脚本会检查这一点并给出明确提示。

---

## 二、你需要下载两个东西

1. **月声整合包**（约 8.1 GB）——包含后端推理程序、模型、侧车服务、启动脚本
2. **月声插件**（很小）——从 GitHub 获取：`https://github.com/<你的账号>/ST-MoonVoice`

两件事是分开的：整合包负责"让电脑能合成语音"，插件负责"让酒馆会用它"。

---

## 三、使用流程

### 第 1 步：解压整合包

解压到纯英文路径，例如 `D:\MoonVoice\`。解压后应该是这样：

```
D:\MoonVoice\
├─ readme.txt                  ← 先看这个（纯文本，记事本能打开）
├─ 启动webui.cmd               ← 日常用这个
├─ 启动局域网服务.cmd           ← 手机 / 平板要连的时候用
├─ 启动后端.cmd                只想单独控制后端时用
├─ 停止全部.cmd                关掉服务
├─ 放行防火墙.cmd              局域网连不上时单独再试
├─ backend\                    推理程序 + 模型（约 7.9 GB）
├─ sidecar\                    工作台服务（moonvoice-sidecar.exe）
├─ data\                       ← 你的数据，都在这里
│   ├─ voices\                 音色库
│   └─ pjy\                    场景音效
└─ 文档\                       本说明 + 许可文件
```

> `backend` / `sidecar` / `data` 用英文名是必须的：后端是 C++ 程序，
> 按 ANSI 代码页打开文件，路径含中文时连模型都读不到。
> `文档\` 不参与程序读写，保留中文名方便你找。

### 第 2 步：双击 `启动webui.cmd`

脚本会依次检查路径、拉起后端（**首次加载模型要 15~40 秒，请耐心等**）、拉起侧车，
最后打印两个地址：

```
工作台      http://127.0.0.1:7881/       ← 建音色、管场景音效
后端界面    http://127.0.0.1:7870/
```

**窗口不会自己关闭**，看完按任意键即可关掉——服务在后台继续跑。

> 如果杀毒软件报警：PyInstaller 打包的程序常被误报。加信任/白名单即可。
> 源码是公开的，可以自己检查。

### 第 3 步：建你的第一个音色

打开 <http://127.0.0.1:7881/>，在「音色库」里上传：

| 字段 | 要求 |
| --- | --- |
| 参考音频 | **5~15 秒**清晰人声，无背景音乐、无混响、无第二个人说话 |
| **逐字稿** | **必填**。音频里说了什么就一字不差地写什么（含语气词） |
| 标签 | 选「性别-年龄段」，决定 NPC 自动分配时会不会用到它 |

**逐字稿是整个流程里最容易出错、也最影响效果的一步。** 写错一个字，克隆相似度会明显下降。
上传时程序会做响度体检：太吵（大喊）或太轻都会提示你换一段。

- 带标签的音色会归入 `data\voices\<性别-年龄>\` 子文件夹
- 根目录 `data\voices\` 下的音色留给主角手动指定

### 第 4 步：把插件装进酒馆

在 SillyTavern 里：**扩展 → 安装扩展 → 填入仓库地址**，或者手动把插件文件夹放到：

```
<SillyTavern>\public\scripts\extensions\third-party\ST-MoonVoice
```

**文件夹名必须正好是 `ST-MoonVoice`**——酒馆按文件夹发现扩展，插件内部也用它定位自己。

装好后刷新页面，扩展列表里会出现 **「古木兆月:月声-TTS」**。

> ✅ **不需要改任何设置。** 插件的三个地址默认就指向 `127.0.0.1:7881`，
> 和整合包的侧车完全对得上。

### 第 5 步：在酒馆里用起来

1. 打开插件的设置面板，**开启「提示词注入」**（默认是关的）。
   它会让大模型按固定格式输出，插件才能正确切句和配音：

   ```
   [角色名|性别-年龄段][情感描述][场景]“内容”
   ```

2. **给角色绑定音色**：点消息上的 ⚙️ 打开配音面板，给每个角色选一个音色。
   没绑定的角色，如果开了「NPC 自动音色」，会按台词里的 `性别-年龄段` 标签自动挑。

3. **开始朗读**：点消息上的 🔊 播放整段，或者直接点正文里任意一句台词单独播放。

4. **浮窗播放器**控制音量、语速、上一句/下一句；人声音量和环境音音量是分开调的。

### 第 6 步（可选）：场景音效

把音频文件放进：

```
data\pjy\环境音效\     循环播放，换场景时淡入淡出
data\pjy\事件音效\     只响一次，叠在环境音之上（敲门、干杯这类）
```

**文件名必须和大模型在第三个方括号里写的一模一样**（区分大小写），例如 `雨声.wav`
对应台词里的 `[雨声]`。写 `[]` 就是停止环境音。
支持 `.mp3 / .wav / .ogg / .m4a / .aac / .flac`。

### 第 7 步：不用了就关掉

双击 `停止全部.cmd`。它会停掉后端和侧车两个进程。

## 四、常见问题

**启动后一直等不到"就绪"**
看 `backend\logs\` 里的日志。最常见的原因是显存不足——模型约需 7 GB，
关掉游戏、浏览器硬件加速、其它 AI 程序再试。另外确认显卡是 NVIDIA。

**路径里有中文**
后端起不来。把整合包移到纯英文路径（如 `D:\MoonVoice\`）重新启动。

**杀毒软件报毒 / 文件被删**
PyInstaller 打包的程序常见误报。把整个整合包目录加入信任列表。
本程序源码公开，可自行审查或自行构建。

**插件装了但列表里没有**
文件夹名不对。必须是 `ST-MoonVoice`，不能是 `ST-MoonVoice-main` 或 `ST-MoonVoice-1.0`。

**点播放没反应**
侧车没在跑。浏览器打开 <http://127.0.0.1:7881/health> 看看有没有回应；
没有就重新双击 `启动webui.cmd`。

**克隆出来的声音不像**
九成是逐字稿的问题。逐字稿必须和参考音频里说的话**逐字一致**，包括语气词。

**某句台词没读到**
它没被识别成对白。检查那行是不是符合
`[角色名|性别-年龄段][情感描述][场景]“内容”`——尤其别漏掉行首的两个方括号。

**想换电脑 / 备份**
把整个 `data\` 文件夹拷走就行，你的音色库和场景音效都在里面。
升级整合包时也**不要把 `data\` 覆盖掉**。

## 五、整合包里有什么、没有什么

**有**：后端推理程序（audio.cpp，Apache-2.0）、Breeze TTS 2 模型权重、月声侧车服务、启动脚本、许可文件

**没有**（需要你自己准备）：
- **音色库**——里面是别人的声音样本，涉及声音权，不能随包分发
- **场景音效**——体积大，且部分内容不适合公开分发
- 插件本体——从 GitHub 单独安装
