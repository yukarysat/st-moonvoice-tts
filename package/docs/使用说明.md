# 月声 (MoonVoice) 使用说明

一个**本地运行的语音生成服务**：自己造音色、自己合成语音，全程离线，数据不出本机。

它不依赖任何其它软件 —— 解压、双击、用浏览器打开工作台就行。对外提供 HTTP 接口，
所以任何能发 HTTP 请求的程序都可以调用它。

---

## 一、开始之前：确认机器能跑

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 64 位 |
| 显卡 | **NVIDIA 独显**。显存要求取决于放哪一档模型，见第二节 |
| 驱动 | 支持 CUDA 13.3 的较新驱动 |
| 硬盘 | 满血包解压后约 **7.9 GB**，无模型包约 **1 GB**；都建议留 **12 GB** |
| 网络 | 只在下载时需要；解压后完全离线可用 |

经验公式：**需要的显存 ≈ 模型文件大小 + 0.25 GB**，另需给桌面留 1 GB 左右。
放哪一档由启动器自动判断，装不下会直接告诉你。

> ⚠️ **解压路径必须是纯 ASCII（建议纯英文），且不要有空格。**
> 例如 `D:\MoonVoice\` ✅　`D:\月声\` ❌　`C:\Program Files\月声\` ❌
>
> 这不是猜测：后端是 C++ 程序，在 Windows 上按 **ANSI 代码页**打开文件，
> 路径里出现中文等非 ASCII 字符就读不到模型。启动脚本会检查这一点，
> 发现中文路径会拦住并说明原因。

## 二、模型：放哪个就用哪个

整合包有两种发布形式：

- **满血包** —— 已含 bf16 模型，解压即用，本节可以跳过
- **无模型包** —— 不含模型（体积小很多），需要自己下一档放进去

### 怎么放

模型是单独打包的，文件名形如 `MoonVoice-model-q5_k.zip`。
解压得到的是一个 `backend\` 目录 —— **把它拖进整合包根目录**即可
（Windows 会提示合并/替换，同意即可）。也可以直接把 `.gguf` 文件复制到：

```
backend\models\Breeze-TTS-2-GGUF\
```

**不用改任何设置。** 放多个档位也行：启动器会读显卡显存，自动挑最好的一档，
并在启动窗口里打印用的是哪一个，例如：

```
模型：q5_k   需要约 4601 MiB 显存
显卡 8192 MiB，模型目录里有 2 个档位
```

想固定用某一档，就只留那一个文件（最直观的"选择"就是删掉别的）。

### 各档位对照

| 档位 | 文件大小 | 需要显存 | 适合显卡 | 音质 |
| --- | --- | --- | --- | --- |
| `bf16` | 6.8 GB | 约 7.1 GB | 12 GB 以上 | 最好（原版） |
| `q8_0` | 4.6 GB | 约 4.9 GB | 8 GB | 与 bf16 分辨不出 |
| `q6_k` | 4.5 GB | 约 4.8 GB | 8 GB | 与 bf16 分辨不出 |
| `q5_k` | 4.3 GB | 约 4.5 GB | 6 GB | 与 bf16 分辨不出（**推荐**） |
| `q4_k` | 4.0 GB | 约 4.3 GB | 6 GB 更从容 | 略有损失，可以接受 |

说明：

- 后四档是同一个模型的不同压缩档位（量化）。**量化只压了 539 个二维权重矩阵**，
  其余 1072 个张量（归一化层、音频编解码器等）保持 16 位精度，所以音质下降
  比一般量化小得多，这也是 6.84 GB 只能降到约 4 GB 的原因。
- 更小的 `q3_k` 已实测**音质明显退化**（频谱与音高波动两项都是离群值），不提供。
- **4 GB 显存的显卡任何一档都装不下**。那样的机器只能用纯 CPU 模式
  （能跑，但比实时慢好几倍，适合偶尔生成几句，不适合听书）。

## 三、解压

解压到纯英文路径，例如 `D:\MoonVoice\`。解压后结构：

```
D:\MoonVoice\
├─ readme.txt                  纯文本快上手（记事本可直接打开）
├─ 启动webui.cmd               ← 日常用这个
├─ 启动局域网服务.cmd           让手机 / 平板 / 另一台电脑也能用
├─ 启动后端.cmd                同「启动webui」，但不打开工作台页面
├─ 停止全部.cmd                关掉服务
├─ 放行防火墙.cmd              局域网连不上时单独再试
├─ backend\                    推理程序（满血包另有模型，约 7.9 GB）
├─ sidecar\                    工作台服务（moonvoice-sidecar.exe）
├─ data\                       ← 你的数据都在这里
│   ├─ voices\                 音色库
│   └─ pjy\                    场景音效
└─ 文档\                       本说明 + 许可文件
```

> `backend` / `sidecar` / `data` 用英文名是必须的（同上：后端读不了中文路径）。
> `文档\` 不参与程序读写，所以保留中文名方便你找。

## 四、启动与关闭

双击 **`启动webui.cmd`**。它会依次检查路径、拉起推理服务（**首次加载模型要 15~60 秒**，
窗口里会一直打点）、拉起工作台服务，最后自动打开浏览器并打印：

```
工作台      http://127.0.0.1:7881/       ← 所有操作都在这里
后端界面    http://127.0.0.1:7870/
```

启动器窗口**跑完会自己关掉**，服务在后台继续运行 —— 它们各自有自己的最小化窗口
（「月声后端」「月声侧车」），那两个**不要关**。

只想给酒馆插件用、不需要工作台页面的，双击 **`启动后端.cmd`**：做的事与
`启动webui.cmd` **完全相同**，唯一区别是不自动打开浏览器。

| 文件 | 用途 |
| --- | --- |
| `启动webui.cmd` | 日常用。推理服务 + 侧车 + 自动打开工作台，只允许本机访问 |
| `启动局域网服务.cmd` | 让同一 WiFi 下的其它设备也能用（见第六节） |
| `启动后端.cmd` | 与「启动webui」完全相同，但**不打开工作台页面**；只用酒馆插件时用它 |
| `停止全部.cmd` | 关闭所有服务 |
| `放行防火墙.cmd` | 局域网连不上时单独再试（UAC 点过「否」之后） |

> 杀毒软件可能对 `moonvoice-sidecar.exe` 报警 —— 打包出来的程序常被误报。
> 加信任即可；源码是公开的，可以自行检查或自行构建。

## 五、工作台

浏览器打开 <http://127.0.0.1:7881/>。三个页签：

### 合成

选一个音色 → 写台词 →（可选）写情感描述 → 生成。

- **音色**：下拉里列出音色库里所有**已配逐字稿**的音色，缺逐字稿的会灰掉并标注
- **台词**：要念的内容
- **情感描述**：决定这句话「怎么说」（语气、情绪、语速、音色）。留空则用该音色的默认指令
- **cfg**：越大情绪越强，但语速会变慢，默认 4 差不多
- **seed**：同样的 seed + 同样的输入 → 同样的输出。想复现就固定它

#### 直接拖一段参考音频进来试

「音色」下面有一块虚线框：**点它可以选择参考音频，也可以把音频文件直接拖到框里**。
用它可以不先建音色就试听一段声音：

1. 拖入或选择一段音频（wav / mp3 / flac / ogg，建议 5~15 秒、干净单人、无背景音乐）
2. 填 **逐字稿** —— 这段音频里说了什么，必须**逐字一致**。Breeze 靠它对齐音素，
   写错、漏字都会明显拉低相似度，所以这一栏是必填，空着会直接拒绝生成
3. 点「生成」即可试听

这段音频**只是本次合成临时用**，不会进音色库，也不会出现在音色下拉里。
觉得好用就点 **「把这段音频存入音色库」**（选标签、填文件名），之后它会作为正式音色出现，
并且自动帮你选中。

> 存入音色库的音色会长期当克隆样本，**建议用平稳的片段**——
> 带情绪的样本会把那种情绪传染给之后由它生成的每一句话。

生成后可以试听，也可以点 **「保存到音色库」** 把它存成一个新音色 —— 逐字稿取
「台词」栏。用某个音色合成出满意的效果时，这样就能留成新音色，或当另一段参考音频用。

页面下方是本次会话的生成历史，关掉页面就没了。

### 声音设计

**不需要任何参考音频**，只用一句描述凭空造一个音色。

1. **音色描述** —— 这个声音「是什么样」。例：`一位四十多岁的中年男性，声音醇厚低沉，吐字清晰。`
2. **情感描述** —— 这段试听「怎么说」。**建议保持平稳**：参考音频会作为克隆样本
   长期使用，带情绪的样本会把那种情绪传染给之后由它生成的每一句话
3. **试听文本** —— 试听要说的话。它会被保存为该音色的**逐字稿**，所以务必与音频一致

生成 → 试听 → 满意就点 **「保存到音色库」**（选标签、填文件名）。

### 音色库

管理所有音色。**语料库就是文件夹**，页面里也能操作。

加一个音色需要两样东西：

| | 要求 |
| --- | --- |
| **参考音频** | 5~15 秒，清晰的单人说话声。不要背景音乐、不要混响、不要两个人同时说 |
| **逐字稿** | **必填**。音频里说了什么就一字不差地写什么（含语气词） |

**逐字稿是整个流程里最容易出错、也最影响效果的一步。** 写错一个字，克隆相似度
就会明显下降。上传时程序会做响度体检：太吵（在喊）或太轻都会提示你换一段。

标签决定音色归到哪个子文件夹（`data\voices\<性别-年龄>\`），也决定它会不会被自动分配。
放在根目录 `data\voices\` 下的音色没有标签，只供手动指定。

### 场景音效

四个子文件夹 = 四条轨，决定播放行为：

```
data\pjy\环境音效\      循环播放，换场景时淡入淡出；永不被事件音打断
data\pjy\环境音效01\    也是循环，可与上一条同时播放（适合放 BGM）；
                       会被 事件音效01 打断
data\pjy\事件音效\      只响一次，叠在循环音之上；每次出现都响
data\pjy\事件音效01\    只响一次，且只在场景名变化时响（同名重复的台词不会
                       反复响）；触发时打断 环境音效01
```

**同名跨文件夹会一起播**：把 房间底噪 / BGM / 开门声 都命名为 `室内_房间`，
分别放进三个文件夹，使用方写 `[室内_房间]` 时三处同时响。

**打断**：`环境音效01\车辆引擎声.ogg`（引擎）+ `事件音效01\刹车.ogg`（刹车）——
写 `[车辆引擎声]` 起引擎，某句写 `[刹车]` 就刹车响一次、引擎停掉，之后**再写
`[车辆引擎声]` 会重新起播**（同名就重启）；想让车一直停着，台词就别再写那个名字。

文件名就是标签名（`雨声.ogg` ↔ 使用方写 `雨声`，不含扩展名）。支持
`.mp3 / .wav / .ogg / .m4a / .aac / .flac`（后缀大小写不敏感）。

**随包已附带 9 个**（8 环境音 + 1 事件音，都在旧的 `环境音效\` 与 `事件音效\` 下），
出处与处理见 `文档\NOTICE` 第 7 节。想加更多见 `data\pjy\_说明.txt` ——
注意**素材版权要你自己确认**。

## 六、局域网：让别的设备也能用

双击 **`启动局域网服务.cmd`**。它会：

1. 确保后端在跑
2. 检查 7881 是否已放行；没有就弹 UAC 请求提权添加规则（**只允许同一网段**）
3. 把工作台服务**自动切换**成监听 `0.0.0.0`（原本是本机模式的话会先停再起）
4. 探测本机局域网地址并打印出来

之后同一 WiFi 下的手机 / 平板 / 另一台电脑可以：

- **用浏览器直接开工作台**：`http://<打印的地址>:7881/`
- **调用 HTTP 接口**：见下一节

> ⚠️ 工作台服务**没有任何鉴权**。开放期间，同一局域网内任何人都能用你的 GPU
> 合成语音，并读取音色库与逐字稿。只在可信网络里这样用，不要暴露到公网。
>
> 想收回局域网访问：双击 `启动webui.cmd`，会自动切回仅本机。

## 七、HTTP 接口

给想自己接的程序用。默认监听 `127.0.0.1:7881`（局域网模式下是 `0.0.0.0:7881`）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 健康检查：后端状态、音色数，以及本包的**出处署名**（`about` 字段） |
| POST | `/tts` | 合成。JSON：`text`、`prompt_audio`（音色 id）、`instruction`、`guidance_scale`、`seed` |
| POST | `/design` | 声音设计（无需参考音频）。JSON：`text`、`instruction`、`guidance_scale`、`seed` |
| GET | `/voices` | 音色库列表（含 `filename`、`tag`、`ref_text`、`ready`） |
| POST | `/api/v1/upload` | 上传参考音频。multipart：`file`、`tag`、`name`、`ref_text` |
| GET | `/voices/{id}/audio` | 取音色音频 |
| PUT | `/voices/{id}` | 改逐字稿等元数据 |
| POST | `/voices/{id}/move` | 移动到标签文件夹 |
| DELETE | `/voices/{id}` | 删除音色 |
| GET | `/api/v1/tags` | 11 个标签及各自数量 |
| GET | `/api/v1/scene_audios` | 场景音效清单（四条轨：环境音 / 环境音效01 / 事件音 / 事件音效01） |
| GET | `/pjy/<路径>` | 场景音效静态文件 |
| GET | `/` ／ `/manage` | 工作台 ／ 音色库管理页 |

例：

```bash
curl -X POST http://127.0.0.1:7881/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"今天天气真好。","prompt_audio":"女-青年/女青01.wav","instruction":"语气轻快","guidance_scale":4,"seed":42}' \
  --output out.wav
```

音色 id 就是**相对 `data\voices\` 的路径**，例如 `女-青年/女青01.wav`。

## 八、常见问题

**双击后一直打点，两分钟还没好**
最常见是显存不够（bf16 约需 7 GB；换更小的档位可降到 4.3 GB 左右，见第二节）。关掉游戏、浏览器硬件加速、其它 AI 程序再试。
其次确认显卡是 NVIDIA。后端日志在 `backend\logs\`。

**路径里有中文**
起不来。把整个文件夹移到纯英文路径再启动。

**杀毒软件报警 / 删了文件**
打包程序常见误报。把整个目录加入信任列表。

**点了生成没反应**
先看后端是否还活着：`http://127.0.0.1:7870/health`。服务挂了就重新双击 `启动webui.cmd`。

**合成很慢**
第一次请求要加载模型，之后单句合成大致与音频时长同量级。显存不足会退化得很厉害。

**克隆出来的声音不像**
九成是逐字稿的问题。参考音频里说了什么，逐字稿就必须**逐字一致**地写什么。

**想换电脑 / 备份**
把整个 `data\` 拷走就行。升级整合包时**不要把 `data\` 覆盖掉**。

## 九、包里有什么、没有什么

**有**：

- 后端推理程序（audio.cpp，Apache-2.0）
- 工作台服务（月声侧车）
- 启动脚本、说明与许可文件
- **22 个样例音色**（7.8 MB，按 11 个标签分好，附逐字稿）—— 解压就能直接合成
- **9 个场景音效**（23 MB，8 环境音 + 1 事件音）
- 满血包另有 **Breeze TTS 2 模型权重**（bf16）；无模型包没有，需自行下载（见第二节）

样例音色由 Breeze TTS 2 以**语音设计**方式生成，不是真人录音。
场景音效出自 SONNISS 的 `#gameaudiogdc` 免费音效包，随包前已折叠成立体声、
转码为 OGG。详见 `文档\NOTICE`。

**没有**（需要你自己准备）：

- 其它音效素材 —— 出处与授权无法确认的一律不附带，请自行准备有权使用的
  文件（正规来源见 `data\pjy\_说明.txt`）
- 你自己的音色 —— 用参考音频加，或者用「声音设计」造
