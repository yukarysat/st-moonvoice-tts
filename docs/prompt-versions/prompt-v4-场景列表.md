# 格式输出规范
**描写任何角色（主要角色、NPC、路人、旁白）说话或叙述时，必须严格遵守格式，每句单开一行**

## 格式：
[角色名|性别-年龄段][情感描述][场景]“内容”

### 角色名：
当前说话的人物名称。**名字后面必须用竖线附上「性别-年龄段」标签**，从下列 11 个里选一个最贴切的：

男-儿童 / 男-少年 / 男-青年 / 男-中年 / 男-老年
女-儿童 / 女-少年 / 女-青年 / 女-中年 / 女-老年
中性-未定

- 旁白、环境描写、心理叙述固定写 `[旁白|中性-未定]`
- 判断不了性别、非人类、群体，一律用 `中性-未定`
- 标签必须来自上面的列表，不要自创
- 名字里不要出现竖线以外的特殊符号

### 情感描述：
这是写给配音演员的**表演指令**：一句话说清「这句该怎么念」。
不要从固定词表中选择（别只写“开心”“生气”），也不要概括剧情。

**唯一的判断标准：只写「能从声音里听出来的」东西。**

可以从下面挑一两个角度来写（不必面面俱到）：
- 情绪与态度：怀着什么心情说这句话
- 语气与音色：声音是什么质感（清亮 / 沙哑 / 慵懒 / 强压着笑意）
- 语速与节奏：偏快偏慢、在哪里停顿、哪里拖长
- 音量与气息：大声 / 耳语 / 送气 / 叹气式地说话

**不要写听不出来的东西：**
- 身体动作：端起茶杯、注视着她、转过身、站起身
- 外貌与表情细节：粉瞳弯成月牙状、脸颊泛红、长发垂落
- 心理活动与剧情：他在犹豫、她想起了往事

动作如果确实改变了说话方式，就把它**翻译成听起来的样子**，而不是照抄动作：
- 「抿了一口热茶」→ 语速舒缓，尾音放松
- 「疲惫地坐下」→ 声音发沉，气息不足，语速拖慢
- 「甜甜地笑着」→ 语调上扬，含着笑意

要求：
- 10~30 字
- 不要出现 ] 符号
- 语言与内容保持一致（中文用中文描述，英文用英文）
- **任何一行都不能省略情感描述**
- **每写完一行自查**：里面出现了「端起 / 看着 / 站着 / 走向 / 瞳孔 / 脸颊」这类词吗？
  出现了就是写错了，改成它听起来的样子。

**旁白的情感描述**默认填：
[平静客观的叙述语气，语速适中，吐字清晰，情绪平稳]
可按当前场景气氛微调（如紧张场景写「压低声音，语速稍快，带着一丝不安」），但不可留空。

### 内容：
用「」或 “” 包裹台词或叙述内容。

### 场景：
仅从下面的列表中选择，避免自创；没有合适的就写空的方括号 `[]`。
**同一场戏里选定一个就保持一致**，不要在多行之间来回切换——换了标签环境音会重新开始，听起来一顿一顿的（雨声那几个变体尤其明显，挑一个用到底）。
#### 正常场景列表：
乡村清晨、公园氛围、海滨城市氛围、夏季氛围、城镇闹市、沙滩_海浪、海鸥_鸣叫、脚步_沙滩、雨声_室内、雨声_室内_小雨、雨声_滴在雨伞上、厨房_切菜、厨房_煎食物、浴室_淋浴、脚步声木地板、脚步声_跑步

## 格式示例：
[小明|男-少年][语气轻快上扬，带着藏不住的笑意，语速偏快][公园氛围]“今天的天气真好呢。”
[旁白|中性-未定][平静客观的叙述语气，语速适中，吐字清晰，情绪平稳][公园氛围]“他悠闲地在公园中漫步，看着来往的人群。”
[小雪|女-少年][声音低沉缓慢，带着压抑的鼻音，像刚哭过][雨声_室内]“我没事，真的没事。”
[中年车夫|男-中年][语气粗粝，语速偏慢][城镇闹市]“客官，坐稳了。”
[爱可丝|女-青年][慵懒满足，语速舒缓，尾音发软][厨房_切菜]“这可是你说的哦，不许反悔。”
