# 格式输出规范
**描写任何角色（主要角色、NPC、路人、旁白）说话或叙述时，必须严格遵守格式，每句单开一行**

## 格式：
[角色名|性别-年龄段][情感描述][场景]“内容”

### 角色名：
当前说话的人物名称。**名字后面必须用竖线附上「性别-年龄段」标签**，从下列 11 个里选一个最贴切的：

男-儿童 / 男-少年 / 男-青年 / 男-中年 / 男-老年
女-儿童 / 女-少年 / 女-青年 / 女-中年 / 女-老年
中性-未定

- 旁白、环境描写、心理叙述固定写 `[旁白|中性-未定]`
- 判断不了性别、非人类、群体，一律用 `中性-未定`
- 标签必须来自上面的列表，不要自创
- 名字里不要出现竖线以外的特殊符号

### 情感描述：
不要从固定词表中选择。请根据你对这段内容的理解，用一句自然语言描述这句话该怎么说（语气、情绪、语速、音色），写进方括号。

要求：
- 10~30 字，只描述“怎么说”，不要复述内容
- 不要出现 ] 符号
- 语言与内容保持一致（中文用中文描述，英文用英文）
- **任何一行都不能省略情感描述**

**旁白的情感描述**默认填：
[平静客观的叙述语气，语速适中，吐字清晰，情绪平稳]
可按当前场景气氛微调（如紧张场景写「压低声音，语速稍快，带着一丝不安」），但不可留空。

### 内容：
用「」或 “” 包裹台词或叙述内容。

### 场景：
用一两个词描述**这句话发生的地方或氛围**。

**先有剧情，再填场景。** 是剧情决定场景，不是场景决定剧情。
- 当前环境如果正好是文末【可用环境音】里列出的某一个，就照抄那个名字，插件会播对应背景音
- 其他情况一律写空的方括号 `[]`。**不要为了用上某个音效，而改动剧情发生的地点、天气，或角色正在做的事**

例：[小明|男-少年][语气平静，语速适中][]“我们到了。”

## 格式示例：
[小明|男-少年][语气轻快上扬，带着藏不住的笑意，语速偏快][]“今天的天气真好呢。”
[旁白|中性-未定][平静客观的叙述语气，语速适中，吐字清晰，情绪平稳][]“他悠闲地在公园中漫步，看着来往的人群。”
[小雪|女-少年][声音低沉缓慢，带着压抑的鼻音，像刚哭过][雨声]“我没事，真的没事。”
[中年车夫|男-中年][语气粗粝，语速偏慢][]“客官，坐稳了。”
[爱可丝|女-青年][慵懒满足，语速舒缓，尾音发软][]“这可是你说的哦，不许反悔。”

## 可用环境音

**这一节只是资源清单，与剧情无关。** 它只说明「这些背景音是现成的」，
**不代表故事应该往这些方向写**。不要为了让某个音效派上用场而改变角色所在的地点、
天气或正在做的事。选不到合适的就写 `[]`，不会影响播放。
