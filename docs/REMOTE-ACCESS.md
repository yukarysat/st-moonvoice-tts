# 出门在外也能用：远程访问方案

目标：人不在家时，手机 / 平板 / 笔记本也能照常用**家里那台电脑**的酒馆 + 月声后端（GPU 还是家里的显卡）。

原理一句话：**把手机和家里电脑放进同一个虚拟局域网**（推荐 Tailscale），然后照局域网那套用 —— 插件填的地址从
`192.168.3.113` 换成 Tailscale 给你的 `100.x.y.z` 就行。不需要公网 IP、不需要改路由器、不需要端口转发。

---

## 一、出门前（在家的电脑上做一次）

### 1. 装 Tailscale

1. 到 <https://tailscale.com/download/windows> 下载安装（装完会常驻托盘）。
2. 用**一个账号**登录（Google / Microsoft / GitHub 都行）。
3. 装完后托盘图标 → 记住这台机器的 **Tailscale IP**（形如 `100.x.y.z`），下面统一写作 `<TS-IP>`。

> 也可以跑一次 `远程访问检查.cmd`（本文件夹里）—— 它会打印机器是否有 Tailscale、IP 是多少、
> 端口有没有在监听、防火墙放行没有，并直接给出该填的地址。

### 2. 启动服务（顺序无所谓，两个窗口都要**留着别关**）

- 双击 **`启动webui.cmd`**（后端 + 工作台服务）
- 双击 **`启动局域网服务.cmd`**（把服务切成监听 `0.0.0.0`，并放行防火墙）

> 侧车**已经放行** Tailscale 的地址段（代码里 `_SHARED_ADDRESS_SPACE` 就是 Tailscale/CGNAT），
> 所以远程访问不会被来源校验挡掉。
>
> ⚠️ 但**防火墙**要额外放行一次：原有的规则只允许 `LocalSubnet`，Tailscale 的 `100.x` 会被挡。
> 双击 `放行防火墙.cmd`（开发环境是 `setup\放行防火墙-7881.cmd`）跑一次 —— 它会再加一条只放行
> `100.64.0.0/10` 的规则。**规则按端口放行，所以一条规则对整合包与开发环境都有效**，跑一次即可。
> 跑完用 `远程访问检查.cmd` 确认两条规则都在（第 4 节会列出来）。

### 3. 让电脑别睡

设置 → 系统 → 电源 → 屏幕和睡眠：把"睡眠"改成**从不**（插电时）。否则人一走电脑睡了，远程就断了。

### 4. 手机上也装 Tailscale 并登录**同一个账号**

装完确认能 ping 通或直接访问：手机浏览器打开 `http://<TS-IP>:7881/health` ——
看到一段 JSON 就说明路通了（这是最快的排查点）。

## 二、在外面用的时候

### 1. 打开酒馆

手机浏览器打开 `http://<TS-IP>:8123`（日常酒馆）或 `http://<TS-IP>:8124`（测试酒馆，如果你开了）。

> **如果看到 403「Blocked connection」**：这是酒馆自己的白名单在挡。
> 编辑酒馆根目录的 `config.yaml`，把 `whitelist:` 改成：
>
> ```yaml
> whitelist:
>   - ::1
>   - 127.0.0.1
>   - 192.168.0.0/16
>   - 100.64.0.0/10      # Tailscale / CGNAT
> ```
>
> 保存后重启酒馆。
>
> **建议同时打开密码**（因为组网之后，酒馆相当于放在了"半公开"位置）：把 `basicAuthMode` 改成 `true`，
> 并在下面填好 `basicAuthUser` 的用户名密码；手机首次打开会让你输一次。

### 2. 插件里改三个地址

📝 设置面板 →「服务配置」——把 `127.0.0.1` 换成 `<TS-IP>`：

| 设置项 | 填 |
| --- | --- |
| TTS 服务地址 | `http://<TS-IP>:7881/tts` |
| 音色克隆地址 | `http://<TS-IP>:7881/api/v1/breezetts2_cloning` |
| 音频列表地址 | `http://<TS-IP>:7881/voices` |

> 酒馆的设置存在**服务端**，所以改一次两边都生效；用 Tailscale IP 在电脑上同样能连，可以就这么留着。

### 3. 场景音效与语音

和在家里完全一样 —— 唯一区别是音频要经过一次网络往返，**首句会比平时慢一点**；
之后每句都会进缓存，第二次听同一句就快了。

## 三、备选方案与取舍

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| **Tailscale（推荐）** | 免费、免公网 IP、免改路由器、全程加密、手机流量也能用 | 两边都要装客户端并登录 |
| ZeroTier | 同类，可自建 Moon 节点 | 免费版走公共中继时延迟略高 |
| Cloudflare Tunnel / ngrok | 不用装客户端（手机直接开网址） | 需要域名/账号；**侧车来源校验会挡域名**，得用 `--allow-origin` 显式放行；免费版有带宽与连接数限制 |
| 端口转发 + DDNS | 最"原生" | **不推荐**：酒馆与侧车都没有鉴权，等于把服务挂到公网；还要处理动态 IP |

## 四、常见问题

- **手机能开酒馆但没声音** → 九成是插件那三个地址还是 `127.0.0.1`（手机上 `127.0.0.1` 指手机自己）。
- **`/health` 打不开** → 电脑上的两个 `.cmd` 窗口是不是关了？电脑是不是睡了？Tailscale 两边是不是都登录了？
- **过一段时间就断** → 检查电源设置；Tailscale 会自动重连，但电脑睡着就没办法。
- **换网络（WiFi→流量）后失效** → 正常，Tailscale 会自己重新打洞，等几秒重开页面即可。

> 注：防火墙规则按端口放行，所以跑一次开发环境的 setup\放行防火墙-7881.cmd，整合包那边也一并生效。
